# Trailhead Lodge Template

A multi-page boutique lodge / guesthouse website with accommodations, amenities, reviews, FAQ, contact and a booking widget.

## Stack

Vite, React, TypeScript, Tailwind CSS, shadcn/ui, React Router

## Getting started

```sh
pnpm install
pnpm dev
```

The dev server runs on http://localhost:8080. Build for production with `pnpm build`.

## Structure

Pages live in `src/pages` (Index, About, Accommodations, Booking, Reviews, FAQ, Contact). Shared sections such as `Hero`, `Navbar`, `Footer`, `BookingWidget`, `AmenitiesBlocks` and `TestimonialCarousel` live in `src/components`.

## Customizing

Replace the placeholder copy, contact details and imagery, and wire `BookingWidget` to your own booking backend.

All names, addresses, emails and phone numbers are placeholders.
